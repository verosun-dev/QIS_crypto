QIS CRYPTO — REPOSITORY MAP
Repository guide · 30 October 2026

Purpose
  Build one reproducible spot–perpetual research pipeline shared by the four
  workstreams. Each source directory below contains implemented logic. Future
  work is listed separately at the end, rather than represented by empty files.

Current runnable scope
  OKX BTC-USDT + BTC-USDT-SWAP; positive-basis V0; visible-depth taker replay.
  Two-hour engineering debug with a 30-minute warm-up. The proposed weekly V0.1
  experiment and 24-hour reference are not implemented by this refactor.

2. WORKSTREAM BOUNDARIES

A · Data                  data/ + acquisition scripts
    Deliver timestamped streams, contract metadata, provenance, and quality checks.
B · Signals               features/ + strategies/
    Deliver causal feature definitions and signal eligibility rules.
C · Backtest/validation   backtest/ + evaluation/ + reporting/
    Deliver an auditable event lifecycle, accounting, experiment, and result tables.
D · Execution/risk        core/ + execution/ + risk/ + shared accounting review
    Deliver quantity validation, fill assumptions, fee/funding rules, recovery checks.

Each group changes the same pipeline. Signal modules do not invent fills; execution
modules do not redefine the strategy; accounting owns the shared cash-flow identity.

4. HOW TO READ THIS PROJECT

New member       README -> project_explained -> team_workstreams
Contributor      source README -> architecture -> relevant module and tests
Baseline review  baseline_spec (implemented) -> baseline_review (proposed next stage)
Run review       config -> data_quality_report -> orders/fills/trades -> summary

Commands from the repository root:
  make test
  make demo
  make replay CONFIG=configs/debug.json

The CLI and package name remain unchanged. See architecture.md for old-to-new import
locations and timing contracts.
